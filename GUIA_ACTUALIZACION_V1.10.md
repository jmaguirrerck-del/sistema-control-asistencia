# Actualización V1.10

1. Subir el contenido de esta carpeta a la raíz del repositorio GitHub `sistema-control-asistencia`.
2. Commit sugerido: `Actualización V1.10 - reinicio seguro de datos de prueba`.
3. Esperar el deployment automático en Vercel hasta estado Ready.
4. No reinicializar Neon y no modificar variables de entorno.
5. Para limpiar las pruebas: Administración → Configuración → Mantenimiento de datos → Reiniciar datos de prueba.
6. Leer el detalle, escribir `REINICIAR` y confirmar.

El reinicio conserva: empleados, horarios, configuración de oficina, catálogo de licencias y PINs.
El reinicio elimina: marcaciones/asistencias, licencias y vacaciones cargadas, dispositivos vinculados, QR históricos y auditoría de pruebas.
