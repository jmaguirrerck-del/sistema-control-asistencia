# Actualización V1.12

1. Subir el contenido de esta carpeta al repositorio GitHub `sistema-control-asistencia`.
2. Hacer commit: `Actualización V1.12 - importación histórica licencias 2026`.
3. Esperar el deployment automático de Vercel hasta `Ready`.
4. Entrar a Administración → Importación histórica.
5. Pulsar `Registrar / actualizar PDF histórico`. Esto registra las 265 páginas como fuente de revisión; no duplica páginas si se pulsa nuevamente.
6. Revisar los casos pendientes. Solo al pulsar `Confirmar e incorporar` se crea el registro de licencia definitivo.

No reinicializar la base de datos.
