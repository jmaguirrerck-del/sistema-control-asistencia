# Sistema de Control de Asistencia — V1.30.0

## Mejora principal: reporte mensual individual de entradas y salidas

Se incorpora una opción visible en **Administración → Reportes** para generar el historial mensual de un agente.

### Uso
1. Seleccionar **Mes**.
2. Seleccionar **Agente**.
3. Presionar **Generar reporte mensual**.

### Información diaria
- Fecha y día de la semana.
- Horario previsto.
- Primera entrada.
- Salidas intermedias.
- Reingresos.
- Salida final.
- Estado de asistencia.
- Minutos de atraso.
- Minutos compensados.
- Minutos a compensar.
- Justificación, cuando corresponda.

### Resumen del período
- Días presentes.
- Faltas justificadas.
- Faltas injustificadas.
- Tardanzas.
- Atraso acumulado.
- Minutos compensados.
- Saldo de minutos a compensar.

### Salidas
- **Exportar este agente a Excel**: descarga solo el detalle individual del período.
- **Imprimir / PDF individual**: abre una versión de impresión en formato apaisado A4 con el detalle del agente.

### Compatibilidad
Se mantienen las funciones anteriores del sistema, incluyendo usuarios/permisos y el permiso independiente **Generador de QR (QR_GENERATOR)** con renovación automática cada 3 minutos.
